1.  前言描述
本文档用于说明供应商系统与电池护照（DPP）平台之间的接口调用规则、鉴权方式、请求结构及返回约定，作为供应商联调、测试和上线验收的接口依据。
业务接口采用 HTTPS 传输，POST 请求的 Content-Type 为 application/json；调用前须先通过鉴权接口获取 token，并在后续业务请求的 HTTP Header 中添加 token。
1.1  文档范围
[表格]
接口 | 说明
鉴权接口 | 获取访问令牌并说明令牌的传递、续期及失效处理规则
供应商上传 SN 接口 | 接收供应商外购电池 SN 及生产相关信息，完成业务数据上传
1.2  通用调用约定
[表格]
项目 | 约定
传输协议 | HTTPS
字符编码 | UTF-8
数据格式 | application/json
请求方法 | POST
时间格式 | Unix 时间戳，单位：毫秒
鉴权方式 | 认证接口获取 token，业务请求头传 token
2.  接口集成标准说明
2.1  鉴权接口设计
2.1.1  请求参数及示例
➢  接口用途：
调用真实业务接口之前，需预先获取分配的账号密码，调用鉴权接口获取token，然后在后续接口调用时在http header中添加token:xxx，再调用后续接口
➢  接口设计：
[表格]
接口编码 / 调用频率 | NO1 / 60次/min
接口名称 / 提供方 | 鉴权接口 / DPP平台
调用路径 / 集成方式 | 对接系统→DPP平台 / http restful接口
请求方式 / 数据格式 | POST / JSON
http header | Content-Type:application/jsonapikey:待分配
SIT URL | https://dbpp-qa.saicmotortest.com/open-api/dpp-platform/login
UAT URL | 待提供
PRD URL | 待提供
[表格]
参数名 | 中文说明 | 类型 | 长度 | 是否必填
userAccount | 用户名；测试环境账号，由dpp平台分配 | string | 50 | 是
password | 密码；测试环境密码，由dpp平台分配 | string | 20 | 是
➢  请求示例（JSON）：
[表格]
{  "userAccount": "api_dre_dol",  "password": "xxxxxxxx"}
➢  参数说明：
userAccount、password 和 apikey 均由 DPP 平台分配。POST 请求体必须使用 JSON 格式，账号密码不得通过 URL 参数传递。
2.1.2  返回参数及鉴权逻辑
[表格]
参数名 | 类型 | 长度 | 是否必填 | 说明
code | string | 50 | 是 | 状态编码，为200时表示成功，其他为失败
success | boolean | — | 是 | 是否成功，状态编码为200时为true，否则为false
message | string | 200 | 否 | 接口消息调用结果描述
body | string | 50 | 否 | 账号相关信息
token | string | 200 | 否 | Access Token调用接口凭证
➢  成功返回示例（JSON）：
[表格]
{  "code": "200",  "success": true,  "message": "业务处理成功",  "body": {    "token": <REDACTED>,    "userAccount": "...",    "userDomain": "...",    "realName": "..."  }}
➢  鉴权失败示例（JSON）：
[表格]
{  "code": -7003,  "message": "没有通过权限验证",  "success": false,  "body": null}
➢  鉴权逻辑：
当 code 为 200 且 success 为 true 时，从 body.token 取得调用凭证。后续业务接口必须在 HTTP Header 中添加 token: {token}。认证返回 -7003 时应检查账号、密码及 apikey，重新认证成功后再调用业务接口。账号、密码、apikey 和完整 token 不得写入日志。
2.2  供应商上传 SN 接口设计
2.2.1  接口用途及设计
➢  接口用途：
接收供应商外购电池的 SN、护照二维码、生产地点、生产时间、订单、物料、客户主体、供应商及工厂标识，并写入电池护照（DPP）平台。
➢  接口设计：
[表格]
接口名 | 供应商上传 SN 接口
URL Path | https://dbpp-qa.saicmotortest.com/open-api/dpp-platform/supplier/sn/upload
请求类型 | POST
Content-Type | application/json; charset=UTF-8
token | {token}
➢  处理逻辑：
1. 使用分配的 userAccount、password 和 apikey 调用鉴权接口。2. 当认证结果 code 为 200 且 success 为 true 时，从 body.token 获取调用凭证。3. 在供应商业务请求的 HTTP Header 中添加 token: {token}。4. 请求体按 snList 数组提交，单次最多上传 100 条数据。
➢  请求示例（JSON）：
[表格]
{  "snList": [    {      "boxNo": "BOX20260727001",      "sn": "PACK20260727000000000001",      "passCodes": {"EU": "https://XXX.smil.com/portal?.S=PACK260727000001&.16D=20260727&.Z=7291" },      "workPlace": {        "zh_CN": "中国-河南省-郑州市-二七区",        "en": "Erqi District, Zhengzhou City, Henan Province, China"      },      "workDate": 1784081606000,      "workOrderNo": "WO2607270056",      "orderType": 0,      "materialCode": "BAT-001-55kWh",      "customerCompanyCode": "SAICMOTOR",      "customerCompanyName": "上汽乘用车有限公司",      "productType": 1,      "customerFactoryCode": "6A00",      "supplierIdentityCode": "013191310115MA1G8XXXX",      "supplierCode": "18012988",      "supplierName": "XX新能源科技有限公司",      "factoryIdentityCode": "013191310115MA1G8XXXX"    }  ]}

2.2.2  请求字段说明
[表格]
序号 | 字段名称 | 类型 | 长度 | 是否必填 | 说明
1 | snList | array | 1–100 | 是 | sn列表， 单次调用列表长度不超过100
1.1 | boxNo | string | 64 | 是 | 打包箱号/托盘号/料架号；用来追溯，非业务主键
1.2 | sn | string | 24 | 是 | 电池sn序列号（24位国标码），唯一值，业务主键
1.3 | passCodes | object |  | 是 | 区域和二维码
1.3.1 | key | string | 10 | 是 | 护照码所属国家/地区：传固定值：EU   代表欧盟护照
1.3.2 | value | string | 500 | 是 | 电池护照二维码（电池唯一标识符）示例：https://XXX.smil.com/portal?.S={PACKSN}&.16D={YYYYMMDD}&.Z={random(4)} 
1.4 | workPlace | object | — | 是 | 电池实际生产地点，对象字段
1.4.1 | zh_CN | string | 500 | 是 | 中文：生产地点    示例：中国-上海市-嘉定区
1.4.2 | en | string | 500 | 是 | 英文：生产地点    示例：Jiading District, Shanghai, China
1.5 | workDate | long | 13 | 是 | 实际生产日期时间戳；示例：1784081606000
1.6 | workOrderNo | string | 64 | 是 | 订单号
1.7 | orderType | integer | 1 | 是 | 订单类型，0:用于整车生产 1：售后
1.8 | materialCode | string | 64 | 是 | 零件号
1.9 | customerCompanyCode | string | 32 | 是 | 客户公司主体编号，枚举项：上汽大乘用车：SAICMOTOR泰国：SMCP智己：IM
1.10 | customerCompanyName | string | 200 | 是 | 客户公司名称
1.11 | productType | integer | 1 | 是 | 生产类型；1：外购；默认值1
1.12 | customerFactoryCode | string | 32 | 是 | 客户公司工厂编号， 示例：6A00
1.13 | supplierIdentityCode | string | 22 | 是 | 供应商（制造商）唯一标识符中国的供应商（制造商）取值：【0131】+【所属的统一社会信用代码】
1.14 | supplierCode | string | 32 | 是 | 供应商编码，按照商务关系编码填写。示例：18012988
1.15 | supplierName | string | 200 | 是 | 供应商名称
1.16 | factoryIdentityCode | string | 22 | 是 | 供应商（制造商）工厂唯一标识符中国的工厂取值如下：【0131】+【工厂所属公司的统一社会信用代码】
说明：子字段通过缩进表示层级；类型和长度分别列示；Array 长度表示单次列表数量范围；Object、boolean 无字符长度时以“—”表示。
2.2.3  返回协议及异常处理
➢  成功返回示例（JSON）：
[表格]
{  "code": "0",  "message": "success",  "data": null}
➢  返回字段说明：
[表格]
参数名 | 类型 | 长度 | 说明
code | string | 50 | 业务处理结果码；0表示所有sn处理成功；200表示请求成功，存在单个sn失败的情况，单个sn执行的情况看data的数据
message | string | 200 | 处理结果描述
data | object | — | 返回数据；无返回内容时为 null
➢   HTTP 状态说明：
[表格]
HTTP 状态 | 场景 | 处理建议
200 | 请求受理成功 | 读取 code 和 message 判断业务处理结果
400 | JSON 格式错误或参数校验失败 | 修正请求体后重新提交
401 | 令牌缺失、无效或已过期 | 重新鉴权并重试一次
403 | 当前应用无接口权限 | 检查应用授权范围
500 | 服务端处理异常 | 记录请求标识并联系系统管理员
➢   单个sn业务处理结果码说明：
[表格]
业务码  | 描述 | 处理建议
0000 | 处理 | 
1001 | 格式校验不通过，请检查格式 | 修正请求体后重新提交
1002 | 业务校验不通过，单次请求中sn不允许重复 | 删除重复sn数据
1003 | 业务校验不通过，sn对应的电池护照已激活，不允许重复上传 | 删除重复sn数据
1004 | 格式校验不通过，passcode格式校验错误 | 修正passcode
1005 | 业务校验不通过，公司编码不存在 | 修正请求体后重新提交
1006 | 业务校验不通过，供应商编码不存在 | 修正请求体后重新提交
1007 | 格式校验不通过，工厂唯一标识符不符合格式 | 修正请求体后重新提交
1008 | 其他情况 | 根据具体报错信息处理
➢  失败返回示例（JSON）：
[表格]
{  "code": "200",  "message": "success",  "data":[{“sn”:”sn000”  “code”:”0000”  “message”:null},{“sn”:”sn001”  “code”:”1001”  “message”:”sn序列号长度大于24”},{“sn”:”sn002”  “code”:”1002”  “message”:”序列号重复”},{“sn”:”sn003”  “code”:”1003”  “message”:”sn对应的电池护照已激活，不允许重复上传”},{“sn”:”sn004”  “code”:”1004”  “message”:”passcode重复”},{“sn”:”sn005”  “code”:”1005”  “message”:”公司编码不存在”},{“sn”:”sn006”  “code”:”1006”  “message”:”供应商编码不存在”},{“sn”:”sn007”  “code”:”1007”  “message”:”工厂唯一标识符不符合格式”},{“sn”:”sn008”  “code”:”1008”  “message”:”网络异常”}]}
➢  安全要求：
生产环境必须使用 HTTPS；userAccount、password、apikey、token 及完整请求报文中的敏感字段不得以明文写入日志。批量请求失败时应保留幂等依据，避免重复写入。
